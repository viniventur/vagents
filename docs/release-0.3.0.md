Salvar e imprimir as sessões, num menu do próprio vAgents, e o card estreito legível.

**O que mudou desde a 0.2.1**

- **Salvar e imprimir:** o botão direito abre o menu do vAgents, no lugar do menu do navegador, que não servia aqui. Ficam o **Atualizar**, o **Salvar como** (imagem PNG, PDF, Markdown ou JSON) e o **Imprimir** (também no Ctrl+P), e o **Copiar** quando há texto selecionado. Nos campos de texto continua o menu do Windows.
- **O documento:** o PNG, o PDF e a impressão saem iguais: as sessões à mostra, nos grupos, cada uma com tudo o que o painel mostra e a árvore inteira dos subagentes, no tema de agora (claro ou escuro), em A4 com o fundo até a borda. O Markdown é para ler ou colar; o JSON traz os dados como o app os lê, para outro programa.
- **Os três pontinhos do painel:** ao lado do X, salvam ou imprimem só aquela sessão.
- **Salvo:** a janela de salvar do Windows e, no fim, um recado com o "Mostrar na pasta".
- **O card estreito legível:** numa sessão sem subagentes, o projeto, a branch e a conta viravam "vag…", "m…" e "Trab…". Agora o estado e a idade ficam em cima, e o projeto, a branch e a conta descem para uma linha só deles. Na lista, a branch e a conta quebram a linha em vez de cortar.

**Instalar:** baixe o `vAgents_0.3.0_x64-setup.exe` abaixo e abra. Ele instala só para você, sem pedir administrador. Se uma versão anterior já estiver instalada, instale por cima: os seus grupos, nomes, cores e preferências ficam. O instalador ainda não tem assinatura de código: se o Windows avisar, clique em **Mais informações → Executar assim mesmo**.

**Precisa de:** Windows 10 ou 11 (64 bits) e o Claude Code 2.1 ou mais novo (testado no 2.1.322).
